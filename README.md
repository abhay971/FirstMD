# First MD — Family Walk-In Clinic

Marketing site for First MD, built from a Figma design with React + TypeScript + Vite + Tailwind CSS v4.

## Development

```bash
npm install
npm run dev      # start the dev server (http://localhost:5173)
npm run build    # production build → dist/
npm run preview  # preview the production build
```

## Deployment

Hosted on Vercel. Pushing to `main` triggers an automatic deploy (Vite preset: build `npm run build`, output `dist`).
